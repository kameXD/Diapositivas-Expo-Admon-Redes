# Presentación de Administración de Redes

La presentación HTML de la raíz es la versión maestra aprobada por el usuario.

- No modificar HTML, CSS, JavaScript, textos ni recursos durante una conversión a PowerPoint.
- Para futuros cambios de contenido o diseño, modificar primero la web únicamente si el usuario lo autoriza y esperar su aprobación antes de regenerar el PowerPoint.
- Flujo solicitado: HTML → Revisión → Aprobación → PowerPoint editable.
- Mantener los dos formatos disponibles. El PPTX y su documentación están en `powerpoint/`; el generador y los verificadores están en `scripts/`.
- Conservar las 39 diapositivas y no rasterizar texto, tablas o diagramas reconstruibles. Las imágenes originales del informe pueden permanecer como imágenes, documentadas en `powerpoint/README.md`.
- Verificar la igualdad de textos, la proporción 16:9, la editabilidad y el render de las 39 diapositivas. No afirmar una prueba directa en Microsoft PowerPoint si solamente se ha usado LibreOffice.
